Última actualización: 3 de septiembre de 2026

1. Aceptación de los términos

Al utilizar el sistema KRONOS 360 ("el Sistema"), usted acepta estos Términos y Condiciones. Si no está de acuerdo con alguno de estos términos, no utilice el Sistema.

2. Descripción del servicio

KRONOS 360 es un sistema de trazabilidad y antifalsificación que permite a las empresas proteger sus productos mediante folios únicos, verificación de documentos y auditoría forense.

  • Trazabilidad: Generación de folios únicos con hash encadenado MD-33.
  • Verificación: Validación de productos y documentos sin servidor.
  • Auditoría: Informes forenses con sello temporal ISO 8601.

3. Uso permitido

El Sistema puede ser utilizado para:

  • Verificar la autenticidad de productos y documentos.
  • Generar y gestionar folios de trazabilidad.
  • Exportar auditorías forenses.
  • Gestionar créditos para la generación de folios.

4. Usos prohibidos

No está permitido:

  • Utilizar el Sistema para actividades ilegales.
  • Manipular los folios o la cadena de hash.
  • Intentar vulnerar la seguridad del Sistema.
  • Utilizar el Sistema para falsificar productos.

6. Privacidad y datos

KRONOS 360 NO almacena datos en servidores propios. Toda la información se guarda localmente en el navegador del usuario (localStorage/IndexedDB). Consulte nuestro Aviso de Privacidad para más detalles.

  • Datos almacenados: Folios, créditos, historial de auditoría.
  • Datos NO almacenados: Contraseñas, tarjetas de crédito, documentos originales.
  • Retención: Los datos permanecen en su dispositivo hasta que usted los elimine.

7. Créditos y pagos

El Sistema opera con un modelo de créditos:

  • 1 crédito = 1 folio generado.
  • Precio: $0.50 USD por crédito.
  • Compra mínima: 100 créditos ($50 USD).

Los pagos se procesan a través de Stripe. KRONOSPROYECT no almacena información de tarjetas de crédito ni datos de pago.
